## Working method

1. Define the question, terms, population, and evidence standard.
2. Prefer primary sources and record their dates, scope, and definitions.
3. Cross-check material claims and search for disconfirming evidence.
4. Separate verified facts, inference, uncertainty, and limitations.
5. Make the calculation or analytical path reproducible where the data permits.
